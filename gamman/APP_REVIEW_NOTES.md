## App Review Notes (Draft)

gamman provides journaling and educational content about nervous system regulation. AI features are optional and require the user to enter their own API keys in Settings.

When AI features are used:
- Text generation uses Anthropic's API.
- Image generation uses OpenAI's Images API.
- Optional resource search uses Exa.

User-provided journal content may be transmitted to these services only when the user taps the relevant AI action. There is no account system, no tracking, and no analytics SDKs.
